# 期货研报观点提取需求（初稿）

## 目标

从 `data/` 下的期货研报提取机构观点，回答「哪家机构在何时对哪个品种看多、看空或看震荡，判断依据是什么」。结果应支持按发布日期、机构、品种和时间周期筛选，并能回到原文核对。

## 数据范围

`data/data1/` 和 `data/data2/` 下已解压的资料按 2024 年 3 月的日期归档，共 9,330 份文件，其中 PDF 4,410 份，HTML 4,920 份。样本包括机构早报、晨会纪要和数据日报。

## 提取内容

一份报告可以覆盖多个品种。同一品种的日内、短期和中期判断分别记录。第一版以「一份报告 × 一个品种或合约 × 一个时间周期」为记录单位。

| 字段 | 记录方式 |
| --- | --- |
| 发布日期 | 优先采用报告标注的日期。仅有目录日期时，标明日期来自目录。 |
| 机构、报告标题 | 记录发布机构和报告标题。 |
| 品种、合约 | 保留品种名称。原文明确给出合约时，同时记录合约代码。 |
| 时间周期 | 记录日内、短期、中期或原文写明的其他周期。机构给出周期定义时一并保留。未说明周期时留空。 |
| 方向标签 | 看多、看空、看震荡或未明确。 |
| 原文判断 | 保留「震荡偏强」「预计本周维持区间震荡」等原话。 |
| 主要理由 | 简要概括机构给出的理由，如库存、供需、政策或成本变化。 |
| 操作建议 | 单独记录「观望」「逢低做多」「逢高做空」等建议。原文未给出时留空。 |
| 原文依据 | 保留支持判断的原文摘录、文件相对路径，以及 PDF 页码或 HTML 小节。 |

## 方向判定

| 方向标签 | 常见表述 |
| --- | --- |
| 看多 | 预计上涨、偏强、震荡偏强 |
| 看空 | 预计下跌、偏弱、震荡偏弱 |
| 看震荡 | 预计区间震荡、横盘 |
| 未明确 | 只描述已发生的涨跌、供需情况或操作建议，未给出明确走势判断 |

方向标签以机构对该品种和周期的走势判断为依据。「库存增加，偏空」可能只是对库存这一项因素的评价，应结合该品种的总体判断提取。带有条件的判断需保留条件，避免把「若站稳某价位则看涨」写成无条件看涨。

## 样例

宝城期货在 2024 年 3 月 1 日的有色早报中，对铜 2404 给出了三个周期的判断。 [原文第 1 页](../data/data1/20240301/宝城期货_210703.PDF)

| 时间周期 | 原文判断 | 方向标签 |
| --- | --- | --- |
| 日内 | 震荡偏强 | 看多 |
| 短期（一周以内） | 上涨 | 看多 |
| 中期（两周至一月） | 震荡 | 看震荡 |

大越期货对铁矿石的判断是「预计本周矿价维持震荡运行」，同时给出「I2405：890-915 区间逢高抛空」。方向记为「看震荡」，区间逢高抛空另记为操作建议。 [大越期货原文](../data/data1/20240301/大越期货_210629_0.html)
