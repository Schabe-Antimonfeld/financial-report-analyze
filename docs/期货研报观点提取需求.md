# 期货研报观点提取需求

## 目标

从已采集的期货研报里提取机构观点，回答「哪家机构在何时对哪个品种看多、看空或看震荡，判断依据是什么」。系统支持按发布日期、机构、品种和周期筛选，按日查看观点分布，并能回到原文核对。 [项目任务书](project/AI金融报告分析市场走势.docx)

## 数据范围

`data/data1/` 和 `data/data2/` 下已解压的资料按 2024 年 3 月的日期归档，共 9,330 份文件。按扩展名计，`.pdf` 有 4,410 份，`.html` 有 4,920 份。导入时以文件内容识别实际格式。样本包括机构早报、晨会纪要和数据日报。系统支持 PDF、HTML、PNG。现有资料没有独立 PNG，验收时补充带标注的 PNG 样本。

任务书和研报样本随课程资料提供。将资料放入本地 `docs/project/` 和 `data/` 后，可打开文档中的相对链接。

## 功能与验收

| 功能 | 验收口径 |
| --- | --- |
| 原文入库与读取 | 将采集到的原始字节和来源保存到 MySQL。Python 解析程序按文章 ID 从数据库读取原文及已入库的附件。回读字节与导入时一致，重复导入可安全重跑。 |
| 内容提取与清洗 | 提取 PDF、HTML、PNG 中的正文、表格和来源位置，去除导航、页眉页脚等噪声。PNG 用 OCR 识别，保留原图位置。 |
| 明确观点提取 | 按品种或合约及周期直接提取原文明确方向，保存判断、条件、理由、建议和依据。明确观点直接入库，模型调用次数为零。 |
| 无明确观点时兜底 | 已定位品种且有相关分析描述时，只把对应片段交给 LLM 判断。通过方向和原文引用校验后作为「模型推断」入库。证据不足时保留「未明确」。品种归属、正文读取或原文冲突问题分别记录。 |
| 结果查询与图表 | 列表可筛选并回查原文。图表按品种及周期展示日度方向分布，原文明确观点和模型推断分别展示和统计。 |

采用 Python、MySQL 8 和 Vue 3。逐阶段算法、数据结构和样本验收见技术调研。 [技术调研](期货研报提取技术调研.md)

## 提取内容

一份报告可以覆盖多个品种。同一品种的日内、短期和中期判断分别记录。第一版以「一份报告 × 一个品种或合约 × 一个时间周期」为记录单位。

| 字段 | 记录方式 |
| --- | --- |
| 发布日期 | 优先采用报告标注的日期。仅有目录日期时，标明日期来自目录。 |
| 机构、报告标题 | 记录发布机构和报告标题。 |
| 品种、合约 | 保留品种名称。原文明确给出合约时，同时记录合约代码。 |
| 时间周期 | 记录日内、短期、中期或原文写明的其他周期。机构给出周期定义时一并保留。未说明周期时留空。 |
| 方向标签 | 看多、看空、看震荡或未明确。 |
| 判断来源 | 已有方向时标明「原文提取」或「模型推断」。 |
| 原文判断 | 保留「震荡偏强」「预计本周维持区间震荡」等原话。 |
| 主要理由 | 保留机构给出的相关原句，如库存、供需、政策或成本变化。模型推断的理由另行展示。 |
| 操作建议 | 单独记录「观望」「逢低做多」「逢高做空」等建议。原文未给出时留空。 |
| 原文依据 | 保留原文摘录、文件来源及内容版本，以及 PDF 页码和坐标、HTML 小节或 PNG 像素位置。 |

## 方向判定

| 方向标签 | 常见表述 |
| --- | --- |
| 看多 | 预计上涨、偏强、震荡偏强 |
| 看空 | 预计下跌、偏弱、震荡偏弱 |
| 看震荡 | 预计区间震荡、横盘 |
| 未明确 | 原文没有明确走势判断，兜底也未得到有依据的方向 |

直接提取的方向以机构对该品种和周期的总体判断为依据。「库存增加，偏空」属于因素评价时，保留为该品种的分析理由。带有条件的判断保留原文条件，例如「若站稳某价位则看涨」。模型兜底结果保留推断理由及可核查的原文引文。

## 样例

宝城期货在 2024 年 3 月 1 日的有色早报中，对铜 2404 给出了三个周期的判断。 [原文第 1 页](../data/data1/20240301/宝城期货_210703.PDF)

| 时间周期 | 原文判断 | 方向标签 |
| --- | --- | --- |
| 日内 | 震荡偏强 | 看多 |
| 短期（一周以内） | 上涨 | 看多 |
| 中期（两周至一月） | 震荡 | 看震荡 |

大越期货对铁矿石的判断是「预计本周矿价维持震荡运行」，同时给出「I2405：890-915 区间逢高抛空」。方向记为「看震荡」，区间逢高抛空另记为操作建议。 [大越期货原文](../data/data1/20240301/大越期货_210629_0.html)
